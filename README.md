# سجل المصنع — تطبيق PWA عربي

تطبيق صغير لتسجيل خروج الكرواسون من المصنع إلى:
- زبون
- صالة البيع والعرض

## المزايا
- Mobile-first ومناسب لـ iPhone 12 Pro.
- واجهة عربية RTL.
- يعمل بدون إنترنت بعد تحميل/تثبيت الـ PWA.
- البيانات محفوظة محلياً في `localStorage`.
- عدد الحبات الافتراضي للصندوق الكامل: 40.
- دعم عدة صناديق ناقصة في العملية الواحدة.
- حساب المجموع تلقائياً.
- الدفع للزبون: نقداً / Whish Money / غير مدفوع.
- سجل وبحث وتصفية.
- إمكانية حذف أي عملية محفوظة مع تأكيد قبل الحذف.
- تقرير قابل للطباعة كـ PDF من Safari.

## تشغيله على iPhone

للحصول على وضع Offline الكامل مع Service Worker، يجب تقديم الملفات عبر HTTPS (مثلاً GitHub Pages أو استضافة HTTPS). افتح الموقع مرة واحدة أثناء الاتصال، ثم استخدم Safari > مشاركة > إضافة إلى الشاشة الرئيسية.

بعد تحميل التطبيق والـ assets، يمكن فتحه بدون إنترنت. البيانات نفسها لا تغادر الجهاز لأنها محفوظة في localStorage.

## PDF على iPhone

من شاشة التقارير:
1. اختر الفترة.
2. اضغط «إنشاء / طباعة PDF».
3. في شاشة طباعة iOS كبّر معاينة الصفحة بإصبعين.
4. اضغط مشاركة واحفظها كملف PDF.

## ملاحظة مهمة عن الخط

الواجهة لا تعتمد على Google Fonts أثناء التشغيل؛ الخط العربي يعتمد على خطوط النظام، لذلك تعمل Offline بالكامل. لا توجد قاعدة بيانات أو API أو تسجيل دخول.

## الخصوصية والنسخ الاحتياطي

البيانات محلية على جهاز Safari فقط. مسح بيانات الموقع أو حذف بيانات Safari قد يحذف السجل. لذلك احتفظ بتقارير PDF دورية كنسخ احتياطية.
